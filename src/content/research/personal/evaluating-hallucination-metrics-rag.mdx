# 1. Introduction

Large Language Models (LLMs) have transformed text generation and contextual reasoning across domains. However, their reliance on probabilistic next-token prediction renders them vulnerable to **hallucinations**—generating fluent, authoritative assertions that lack factual backing or directly contradict source contexts [1]. 

In critical sectors such as healthcare, finance, and legal analysis, ungrounded outputs pose severe operational risks [2]. Retrieval-Augmented Generation (RAG) addresses these vulnerabilities by grounding model generations in verifiable, external knowledge stores [3]. By supplying parametric models with non-parametric context at inference time, RAG effectively circumvents knowledge cutoffs and cuts fine-tuning overhead [4].

Despite these benefits, the reliability of a RAG pipeline is bottlenecked by its retrieval phase. If a retriever returns irrelevant or incomplete information, the generation engine is forced to extrapolate, yielding **intrinsic hallucinations** (contradicting the retrieved context) or **extrinsic hallucinations** (introducing unsupported external facts) [5].

Standard automated metrics like BLEU and ROUGE evaluate surface n-gram matches rather than factual alignment, making them poor indicators of generation accuracy [6]. This paper investigates how different retrieval architectures directly influence factual consistency and evaluation metrics in downstream generative tasks.

# 2. Methodology & System Architecture

Our experimental setup models a two-stage RAG pipeline comprising an adaptive retrieval engine and an un-tuned generative model ($M$), specifically `Llama-3-8B-Instruct`.

## 2.1 Retrieval Engine Design

We evaluate three retrieval strategies over an indexed document store $D = \{d_1, d_2, \dots, d_n\}$:

1. **Sparse Retrieval ($Ret_S$):** Utilizes standard BM25 lexical indexing to extract exact keyword matches.
2. **Dense Retrieval ($Ret_D$):** Employs `all-mpnet-base-v2` Sentence Transformers to generate dense vector representations, using cosine similarity for semantic matching.
3. **Dynamic Hybrid Retrieval ($Ret_{\text{Hyb-RRF}}$):** Combines lexical and semantic scores using dynamic weighting and Reciprocal Rank Fusion (RRF).

### Query Expansion Module
To bridge lexical gaps between queries and domain documents, input queries $q$ undergo automated expansion via WordNet. For every term $q_j \in q$, we append top synset terms $T(q_j)$, producing expanded query $q'$:

$$q' = q \cup \bigcup_{j=1}^{|q|} T(q_j)$$

### Dynamic Weighting & Reciprocal Rank Fusion
Instead of static interpolation, retrieval weights are dynamically calibrated based on a term specificity score $S(q')$, calculated using inverse document frequency distribution:

$$S(q') = \frac{1}{|q'|} \sum_{i=1}^{|q'|} \text{tf-idf}(q_i)$$

Sparse weight $w_{Ret_S}$ and dense weight $w_{Ret_D}$ are calculated as:

$$w_{Ret_S} = \alpha \cdot S(q'), \quad w_{Ret_D} = 1 - w_{Ret_S}$$

where $\alpha$ is a normalization constant. Specific queries receive higher sparse weighting, whereas open-ended or conceptual queries favor dense semantic vector matching. Results are combined using weighted Reciprocal Rank Fusion:

$$RRF_{\text{weighted}}(d_i) = \sum_{Ret \in \{Ret_S, Ret_D\}} \frac{w_{Ret}}{\epsilon + r_{Ret}(d_i)}$$

where $r_{Ret}(d_i)$ is the rank position of document $d_i$, and $\epsilon = 60$ prevents division by zero.

# 3. Experimental Setup & Metrics

## 3.1 Benchmark Dataset
Evaluations were conducted on **HaluBench** [7], a unified hallucination benchmark encompassing $13,867$ evaluation pairs across six distinct domains: DROP, HaluEval, RAGTruth, FinanceBench, PubMedQA, and COVIDQA. 

To evaluate overall generation performance, a balanced, human-annotated sample ($HaluBench_{\text{small}}$, $n=300$) was evaluated across both faithful (`PASS`) and hallucinated (`FAIL`) source cases.

## 3.2 Evaluation Metrics

Retrieval effectiveness is measured using standard Information Retrieval metrics at $k=3$:
* **Mean Average Precision (MAP@3):** Measures the average precision across retrieved positions.
* **Normalized Discounted Cumulative Gain (NDCG@3):** Assesses rank-aware document relevance.

Downstream generation quality is calculated using four core factuality metrics:

$$\text{Accuracy} = \frac{\text{Correct Answers}}{\text{Total Samples}}$$

$$\text{Hallucination Rate} = \frac{\text{Factually Inaccurate Answers}}{\text{Total Samples}}$$

$$\text{Rejection Rate} = \frac{\text{Insufficient Context Refusals}}{\text{Total Samples}}$$

$$\text{Adjusted Accuracy} = \frac{\text{Correct Answers}}{\text{Correct Answers} + \text{Hallucinated Answers}} \times 100$$

# 4. Results & Analysis

## 4.1 Retrieval Quality

Evaluating $Ret_{\text{Hyb-RRF}}$ against single-mode retrievers across the full $HaluBench_{\text{orig}}$ dataset confirms significant improvements in context retrieval quality.

| Metric | Sparse ($Ret_S$) | Dense ($Ret_D$) | Hybrid ($Ret_{\text{Hyb-RRF}}$) |
| :--- | :---: | :---: | :---: |
| **MAP@3** | 0.724 | 0.768 | **0.897** |
| **NDCG@3** | 0.732 | 0.783 | **0.915** |

The hybrid retriever achieved an **NDCG@3 of 0.915**, representing an $16.8\%$ performance gain over stand-alone dense semantic retrieval. This gain stems directly from dynamic query expansion, which preserves specific key identifiers while utilizing semantic vector projections for broad intent matching.

## 4.2 Downstream Hallucination Reduction

Improved retrieval accuracy translated directly into decreased downstream hallucinations during generation with `Llama-3-8B-Instruct`.

```
Retrieval Method Performance Comparison (%)
┌──────────────────────┬──────────┬───────────────────┬────────────────┬───────────────────┐
│ Strategy             │ Accuracy │ Hallucination Rate│ Rejection Rate │ Adjusted Accuracy │
├──────────────────────┼──────────┼───────────────────┼────────────────┼───────────────────┤
│ Sparse (BM25)        │  36.79%  │      28.76%       │     34.45%     │      56.11%       │
│ Dense (MPNet)        │  48.83%  │      22.41%       │     28.76%     │      68.54%       │
│ Hybrid (Dynamic RRF) │  80.27%  │      10.37%       │      9.36%     │      88.55%       │
└──────────────────────┴──────────┴───────────────────┴────────────────┴───────────────────┤
```

### Key Observations
1. **Hallucination Suppression:** $Ret_{\text{Hyb-RRF}}$ reduced the downstream LLM hallucination rate to **10.37%**, compared to 28.76% under sparse retrieval.
2. **Context Sufficiency:** The rejection rate (where models refuse to answer due to missing facts) dropped from **34.45%** to **9.36%**, demonstrating higher context recall.
3. **Resilience on Failed Contexts:** On source samples classified as ground-truth failures (`FAIL`), hybrid RAG preserved an accuracy of **77.24%**, whereas sparse retrieval dropped to 39.84%.

---

# 5. Conclusion & Future Directions

This study demonstrates that dynamic hybrid retrieval—combining lexical matching, semantic vector search, WordNet expansion, and Reciprocal Rank Fusion—significantly reduces intrinsic and extrinsic hallucinations in LLM outputs. Providing high-precision contextual grounding reduced LLM generation errors from **28.76% down to 10.37%** across the HaluBench benchmark.

Future work will focus on integrating real-time re-ranking layers (e.g., Cross-Encoders), exploring multi-agent verification frameworks, and extending these evaluation metrics to complex multimodal RAG architectures.

# Math2Model

Math2Model is an educational platform designed to bridge the gap between mathematical foundations and practical artificial intelligence.
The platform helps learners understand how mathematical concepts evolve into algorithms, neural network architectures, and modern AI models. It brings structured learning, research exploration, and practical implementations together in one place.
Math2Model aims to provide a comprehensive learning experience covering the mathematics, theory, research, and implementation behind artificial intelligence.

## Core Features

### 1. AI Curriculum

A structured learning experience covering the mathematical, theoretical, and computational foundations of artificial intelligence.

- Mathematical foundations, including linear algebra and calculus.
- Optimization and neural network fundamentals.
- Deep learning architectures and modern AI systems.
- Transformers and State-Space Models.
- Structured learning paths and topic relationships.
- Mathematical explanations and connections between concepts.

### 2. External Research Papers

A curated collection of external research papers covering artificial intelligence, machine learning, and related fields.

- Explore important AI research papers.
- Discover architectures, algorithms, and optimization techniques.
- Understand research contributions and key concepts.
- Connect research topics with the corresponding AI curriculum.
- Access designated research content after login.

### 3. Personal Research Papers

A dedicated section for original research papers and research work published or shared by the Math2Model creator.

- Dedicated pages for individual research papers.
- Research metadata and publication information.
- Technical explanations and mathematical content.
- Database-backed research-paper management.
- Login-based access to designated research content.

### 4. Practical Implementations

Connect mathematical theory with practical implementation through code walkthroughs and explanations.

- Step-by-step Python implementations.
- Explanations of AI algorithms and architectures.
- Connections between mathematical concepts and code.
- Practical exploration of research ideas.

## Tech Stack

- **Framework:** Next.js (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Structured Content:** JSON
- **Database:** MongoDB for dynamically managed personal research papers
- **Markdown Processing:** react-markdown, remark-gfm
- **Math Rendering:** remark-math, rehype-katex
- **Code Highlighting:** rehype-pretty-code, Shiki
- **Metadata Parsing:** gray-matter, when using Markdown frontmatter
- **Icons:** lucide-react

## Getting Started

To run this project locally:

1. Clone the repository:
   git clone https://github.com/Abhisek-Dash-Official/math2model.git
   cd math2model

2. Install the dependencies:
   npm install

3. Start the development server:
   npm run dev

4. Open http://localhost:3000 in your browser to view the application.
